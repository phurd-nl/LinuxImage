Encrypt your home folder

Required setup before you can use this laptop.

Secure Boot must be enabled first. This protects the encryption key sealed to your TPM.

  1. Restart and open UEFI firmware (F2, Del, or Esc)
  2. Enroll default Secure Boot keys if prompted
  3. Enable Secure Boot → save and exit
