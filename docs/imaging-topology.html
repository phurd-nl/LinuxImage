Imaging topology

How a laptop is imaged today. The bench steps are the imaging SOP. The 2 November plan map is kept at imaging-topology-plan-2026-11-02.html. Update this page when the path changes.

1. Network boot

RunningLaptopUEFI network boot on the imaging VLAN. Power and the cable stay connected.
→
RunningDHCPOffers snponly.efi from 192.168.26.106. DHCP is not on the opsi host.
→
RunningTFTP :69default.ipxe and autoexec.ipxe chain to the kiosk. They retry if that chain fails.
→
Runningboot.ipxe :8091The imaging host looks up the laptop MAC. No saved choice loads the form. A saved choice skips the form.

2. The form, or the saved choice

RunningKioskSmall Linux image. A framebuffer form, not a browser and not the Ubuntu desktop. Kernel is the signed Ubuntu casper vmlinuz.
→
RunningLook upThe imaging host calls NextDesk. It tries infara-scale.nxlink.com, then nextdesk.nxlink.com. The public desk answers. The tech does not pick UAT or Prod.
→
RunningChoice file/var/lib/imaging-kiosk/decisions/<mac>.json. Ticket, person, department, operating system, and checked apps. Expires after 30 minutes. Not served on port 8090.
→
RunningOne network bootStart sets EFI BootNext to the network entry and reboots. That one boot reads the choice file.

The checks follow one rule. A previous laptop with a software list in NextDesk wins. With no list on that laptop, the department pack is checked. With no pack for that department name, the core apps are checked. The form says which rule it used.

A blue iPXE menu is only the fallback when the kiosk does not start. A normal boot does not sit on it.

4. Windows apps, after the operating system is on disk

These run from postinst.d while the imaging cable is still connected. 03b_fetch_kiosk_apps.cmd saves the checked list before Wi-Fi. 70_core_apps.cmd installs that saved list. A miss, or a laptop with no saved choice, installs Chrome, Firefox, KeePass, and Earth Pro.

PieceRole
03b_fetch_kiosk_apps.cmdSaves the checked software from the imaging host before Wi-Fi can move the laptop off that network.
04_wifi_specialize.cmdJoins Nextlink_Corp. The passphrase is staged from a server secret, not from git.
50_opsi-client-agent.cmdDoes nothing. The product copy cannot put the agent installer back under this name.
60_atera.cmdAtera agent on every image.
61_wazuh.cmdWazuh agent on every image.
62_unifi_endpoint.cmdUniFi Endpoint MSI on every image. This is not the UniFi VPN row.
70_core_apps.cmdChecked catalog apps. Uses the list saved by 03b. One extra pass if a selected app fails. The done marker is written only when that pass exits clean.

97_hide_nextadmin.cmdHides the local NextAdmin account.
99_handoff.cmdClears autologon, sets Welcome plus the employee name, and reboots to the work sign-in. The first non-NextAdmin sign-in clears that line.

Department apps are not installed by a login task. That path, lab-provision, is disabled. WiFiman, when checked, is scheduled for the employee’s next sign-in because it does not install as the machine account. WSL turns the feature on now and finishes the distro after a reboot.

5. Where it lives

WhatWhere
Imaging host192.168.26.106. Form and choice API on port 8091, bound to that address (imaging-kiosk.service, /opt/imaging-kiosk). Boot files on port 8090, also bound to that address. Ports 8090 and 8091 do not listen on every interface.
Choices/var/lib/imaging-kiosk/decisions. One JSON file per MAC, colons removed. It expires 30 minutes after Start. Delete it to show the form sooner. http://192.168.26.106:8090/decisions/ returns 404.
Private files/opt/imaging-private, root-only, outside the boot port. NextPass token, Atera link, Wazuh password, UniFi package, and NextAdmin password. Ubuntu recovery phrases go in recovery/<mac>.pass.
Catalog/opt/lab-console/data/catalog. The form and /api/install.json both read it.
Windows productwin11-x64 on the opsi depot, opsiconfd 4.3.59.4, container opsi-server_opsi-server_1.
NextDesk readApp role ImagingRead. The live desk that accepts it is https://nextdesk.nxlink.com. https://infara-scale.nxlink.com still refuses that token.
SourceWindows scripts are in postinst/ in this repo. active/ still runs. retired/ is kept. The kiosk source is fog/opsi/imaging-kiosk.

Ubuntu recovery and lockdown

An Ubuntu Start writes one recovery phrase per MAC and emails a NextPass link to the imaging owner. The link expires after 90 days or 5 views. The host file remains until a vault exists. Imaging that MAC again deletes the old phrase and emails a new one. The laptop copies the phrase while the imaging cable works and deletes its copy after the disk key is set.

The same install denies new inbound connections and allows outbound. SSH, Avahi, rpcbind, and Windows discovery are off. Name resolution, time sync, and printing stay installed, and inbound traffic to them is dropped. Automatic security updates are on. Hibernate, hybrid sleep, and ordinary suspend are masked.

Open

  • The Entra password is supposed to replace the Ubuntu install password on /home at the first online sign-in. That hook has not run on a laptop.
  • UniFi VPN and the NextDesk endpoint are locked on the form and have no package.
  • The opsi client agent is not armed. Identity, software inventory, and bookmark backup were agent products, so they do not run. Wi-Fi join still does.
  • The USB sticks are the old seed. A dock does not set the BIOS. The new-hire group is still added by hand.
